# Seven-arm ablation

Generated by `eval/arms.py`. Never hand-edited.

- 36 scenarios across 3 hazards, held-out seeds
- budget: **5 interventions**, applied at 25% of the horizon
- interventions applied **in the engine** and re-run on the same seed with paired
  randomness — a true counterfactual, not a score under our own rollout model
- 95% intervals are a **paired bootstrap over scenarios**, since every arm sees the
  same seeds

**Read the `vs chance` column, not the `prevented` column.** Protecting five
assets at random already prevents damage, and it does so with a standard deviation
of roughly 176,000 on a single scenario — so an arm that prevents a little is not
doing anything. Arm **AR** is that baseline, and the only honest question is
whether an arm beats it.
